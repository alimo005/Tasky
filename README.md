**Tasky** is a task management application built as part of a Flutter learning course. It is a learning project designed to help manage daily tasks efficiently.

### Key Features
* Add new daily tasks
* Mark tasks as important/priority
* Toggle task completion status
* Delete tasks

### Key Takeaways & Learning Outcomes
Through building this project, I gained hands-on experience with core Flutter concepts. Most notably, I learned state management using **Provider**.
